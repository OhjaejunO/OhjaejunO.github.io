```cpp
void AOJJ_Player::StartSprint(const FInputActionValue& Value)
{
	if (UCharacterMovementComponent* Movement = GetCharacterMovement())
	{
		Movement->MaxWalkSpeed = SprintSpeed;
	}
}

void AOJJ_Player::StopSprint(const FInputActionValue& Value)
{
	if (UCharacterMovementComponent* Movement = GetCharacterMovement())

	}

```

입력 바인딩(같은 커밋, `SetupPlayerInputComponent`) — 뗌을 Completed뿐 아니라 Canceled에도 바인딩한 이유가 주석에 있음:

```cpp
	if (IA_Sprint)
	{
		EnhancedInput->BindAction(IA_Sprint, ETriggerEvent::Started, this, &AOJJ_Player::StartSprint);
		EnhancedInput->BindAction(IA_Sprint, ETriggerEvent::Completed, this, &AOJJ_Player::StopSprint);
		// Hold/Chord 트리거가 붙어 뗌이 Completed 대신 Canceled로 와도 질주가 안 남도록 함께 바인딩.
		EnhancedInput->BindAction(IA_Sprint, ETriggerEvent::Canceled, this, &AOJJ_Player::StopSprint);
	}
```

## 못 찾은/한계 항목

- **ABP 스테이트머신 노드 그래프 자체**: `ABP_Man.uasset`/`ABP_Woman.uasset`는 바이너리라 diff 불가. 스테이트/트랜지션 구조는 **커밋 메시지 + C++ 게터(`IsClimbing`/`ShouldPlayFallAnim`/`IsSwimming`/`IsSwimMoving`) + BlendSpace 이름**에서 역산한 것. 정확한 상태 이름(예: Locomotion↔Jump↔Fall↔Climb↔Swim 전이 조건)은 에디터를 열어야 확정.
- **C++ AnimInstance 클래스 없음**: `Public/`에 UAnimInstance 파생 클래스 없음(ABP는 순수 Blueprint). 유일한 애니 관련 C++는 `AnimNotify_OJJ_Footstep`. 따라서 "ABP 구조를 C++로 인용"은 불가하고, C++는 판정 게터만 제공.
- **점프 애니 '변경 전' 상태**: #357은 "강사님 피드백"으로 애니를 바꾼 것인데, 변경 이전 점프 표현(순수 스테이트머신 기반)의 스크린샷/구체 서술은 커밋 메시지의 "서서 뜬 뒤 늦게 재생" 묘사가 전부.
