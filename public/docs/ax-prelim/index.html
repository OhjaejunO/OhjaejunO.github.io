1마이리얼트립 — 환불 규정 네비게이터

여행 플랫폼 · CS 자동화

문제

취소를 고민하는 여행자는 버튼을 누르기 전 실제로 얼마를 돌려받는지 알 수 없고, CS 담당자는 카테고리·항공사·시점마다 다른 규정을 매번 찾아 같은 유형의 문의에 반복 대응합니다. 국제선은 항공사 운임규정에 여행사 취급수수료(성인 1인 3만원, 매회)가 별도로 붙고, 발권 후 24시간 무료취소는 항공사별 조건이 다르며, 노쇼 시 수수료가 이중 부과됩니다. 규정 파편화로 인한 환불 분쟁이 조정·소송으로 이어진 보도 사례가 있는, 2026년 현재도 갱신 중인 현재진행형 구조입니다.

설계 판단

판정·계산은 100% 결정적 룰 엔진 — LLM은 자연어 예약 설명을 구조화 입력으로 바꾸는 변환만.

규칙에 없는 항공사·상품이 들어오면 임의 추정 대신 '미보유'로 처리하고 확인할 공식 문서를 안내합니다. 금액 계산이 비결정적이 되면 신뢰가 무너지기 때문입니다.

  • 4단계 파이프라인 — 입력 파싱 → 룰 해석 → 결정적 계산 → 리포트 (예상 환불액·수수료 공제 내역·증빙 체크리스트 + 적용 조항 원문 링크)
  • 공식 헬프센터 원문 12개 문서를 규칙 JSON 8파일로 구조화 — 전 규칙에 출처 URL·원문 인용·확인일자 부착
  • 우선순위 로직 — 항공사 운임규정 > 플랫폼 규정, 24시간 룰의 항공사별 예외, 노쇼, 면제 사유
  • 공식 사이트 403 차단 → 블로그 요약 우회 대신 Zendesk 공개 API로 원문만 확보 (2차 출처 배제)

검증

  • 초기 브리핑의 사실 2건을 원문 대조로 정정 — 24시간 무료취소의 "출발 7일 이상" 조건은 하와이안·에티하드·ANA 3사에만 적용(아시아나는 무조건부), 국내선 대한항공·아시아나는 질병 면제 불가
  • 시나리오 7종을 규정 원문과 수동 대조, 경계값·비정상입력 자체검증 32건 통과 (24시간 정각/초과, 출발 168시간 경계, 노쇼, 입력 방어)
  • 오프라인 E2E — 기대 리포트와 바이트 단위 7/7 일치, 클린 폴더 압축해제 후 재현 확인
  • Codex 교차 리뷰 — 입력 검증 4건 + 로직 버그 3건(노쇼·질병 면제 중첩 시 이중수수료 은닉, 재발행·출발 후 항공권의 면제 분기 오류, 저비용항공사 24시간 경계 모호성) 전부 수정 후 재검증
  • 한계 명시 — 규칙은 확보한 12개 문서 범위(전 항공사·전 상품 전수 아님), 규정 개정 자동 감지 미구현

2메디테라피 — 4개국 규제 온톨로지

화장품 · 글로벌 진출 검토

문제

미국 MoCRA, 일본 약기법(화장품/의약부외품 구분), 아세안 화장품 지침, 국내 화장품법 표시광고 규정이 전부 다른 체계로 존재하고 수시로 개정됩니다. 신규 국가 출시나 상세페이지 제작 전마다 담당자가 각국 법령 원문을 수동으로 뒤져야 하는 구조 — 시딩으로 해외 수요를 만들어도 규제를 통과하지 못하면 매출 전환이 막히므로, 규제 온톨로지는 인플루언서 시딩 루프의 전제 조건입니다.

설계 판단

출처 없으면 '미판정' — 모르는 것을 아는 척하지 않는 설계.

공식 원문을 확보하지 못한 규칙(예: 하이드로퀴논)은 온톨로지에 넣지 않고 미판정으로 처리합니다. 규칙 수를 늘리는 것보다 모든 판정의 출처 추적 가능성이 우선입니다.

  • 3단계 파이프라인 — 입력 파싱(전성분 INCI·마케팅 문구·타깃 국가) → 결정적 규칙 매칭 → 리포트
  • 성분 56·문구 26, 총 82개 규칙 — 법령정보센터·FDA/eCFR·후생노동성 고시·HSA/ACD 공식 출처 URL과 확인일자 부착
  • LLM은 INCI 정규화·문구 의미 플래그만 — 플래그는 MEDIUM 등급 캡핑 + "사람 검토 필요" 표기로 시스템 판정과 구분, 개입 결과는 파일로 남겨 검증 가능

검증

  • 실제 공개 제품 5종 양성 판정 + 음성 대조군 2종 통과 — 레티날 스킨부스터 세럼의 KR 판정(나이아신아마이드·아데노신 = 기능성 고시원료)이 실제 "기능성 화장품" 표기와 일치
  • 커버리지 경계 정직 노출 — 일본 한도(0.2%)를 초과하는 BHA 살리실릭애씨드 0.4%는 자동 대조 대신 보수적 MEDIUM 처리, 오탐이 아닌 명시된 경계로 문서에 기록
  • Codex 교차 리뷰 — PDRN 샘플에서 인용 출처의 브라이트닝 문구를 누락한 채 "미백 미표방"으로 단정한 지점을 정정 ("외관 브라이트닝 표현은 있으나 미백 기능성 표방은 아님")
  • 오프라인 E2E — zip을 클린 폴더에 풀어 실행, 재현 확인
  • 한계 명시 — 규칙 82개는 대표 규칙(전수 아님), EU 등 미포함 권역과 일부 성분 한도 자동 대조는 다음 단계

3무신사 — 미입점 브랜드 스카우트 리포트

패션 플랫폼 · 브랜드 발굴

문제

무신사가 AX 인재전쟁 영상에서 직접 정의한 질문 — "고객이 선호할 브랜드를 어떻게 놓치지 않고 찾아낼 것인가" — 에서 출발했습니다. 트렌드 신호는 패션 미디어·검색·커뮤니티에 파편화되어 있어 수동 모니터링으로는 놓치는 브랜드가 생기고, 신호와 입점 사이의 시차가 곧 기회비용입니다.

설계 판단

숫자 계산은 전부 결정적 규칙, LLM은 브랜드명 선별·적합도 판단만 — 그 결과도 파일로 남겨 검증 가능하게.

스코어 산식을 공개해 누구든 같은 입력으로 같은 결과를 재현할 수 있습니다. 백테스트의 사후 확증 편향을 스스로 의심한 결과입니다.

  • 5단계 파이프라인 — 수집(공개 엔드포인트) → 탐지(언급량 증가율 규칙) → 대조(입점 여부) → 스코어 → 리포트
  • score = 100 × momentum × fit × gap — 산식·임계값은 SKILL.md에 명시
  • 일부 소스 응답 실패(403 등) 시 건너뛰고 진행하는 우아한 강등, 오프라인 캐시로 전체 파이프라인 재현 가능

검증

  • 백테스트 — 2022-06 이전 공개 데이터만 입력 → 마뗑킴을 1위(57.68점)로 탐지 → 실제로 5개월 뒤 무신사 입점, 2024년 일본 총판 파트너십으로 이어짐
  • 음성 대조군 — 이미 입점한 마르디메크르디가 낮은 점수로 걸러짐 (공백도 축이 작동한다는 증거)
  • Codex 교차 리뷰 지적 11건 전부 검토·수정 후 재검증
  • 한계 명시 — 과거 시점 데이터는 아카이브 부재로 재현용 픽스처(사실은 전부 공개 보도 URL로 뒷받침), 적중 사례 1건으로 통계적 검증은 아님

4세 플러그인의 공통 설계 원칙

판정은 규칙 · LLM은 보조

규정 판정이 비결정적이면 신뢰가 무너집니다. LLM은 정규화·플래그까지만 담당하고, 판정과 계산은 출처 추적 가능한 결정적 규칙이 수행합니다. 이 원칙은 본선 설계(AX 시딩 엔진)와 AI 콘텐츠 채널의 운영 규칙(이중 출처 교차 확인·출처 우선)으로 그대로 이어집니다.
