🐋 Orca 설치 + AI 연결 가이드
(5분 완성)

AI 에이전트 여러 개를 한 화면에서 부리는 무료 앱, Orca — 직접 쓰면서 정리했어요.

1Orca 설치 (1분)

윈도우 / 맥 / 리눅스 전부 지원, 완전 무료.

  1. 공식 사이트 → onorca.dev/download
  2. 내 운영체제 버전 다운로드 (윈도우 .exe, 맥은 Apple Silicon/Intel 구분)
  3. 설치 후 실행 — 회원가입 없음. 바로 켜집니다.

💡 맥 터미널파: brew install --cask stablyai/orca/orca

2AI 에이전트 연결 (2분)

Orca는 "사무실"이고, 일할 AI는 내가 쓰던 걸 데려옵니다. 기존 구독 그대로 = 추가 비용 0.

클로드 (Claude Code)

npm install -g @anthropic-ai/claude-code

→ 터미널에 claude 입력 → 브라우저에서 로그인 → 끝. Orca가 자동 인식.

코덱스 (ChatGPT)

npm install -g @openai/codex

→ codex 입력 → ChatGPT 계정 로그인. 그록·제미나이도 같은 방식 — 25종 이상 자동 인식.

3첫 사용 (2분)

  1. Orca 실행 → Open Project → 작업 폴더 선택
  2. New Worktree (+) → 에이전트 선택 (예: Claude Code)
  3. 프롬프트 입력 → AI가 일 시작
  4. 병렬의 맛: worktree 하나 더 만들어 다른 AI에게 같은 일 시키기 → 결과 비교 → 승자 채택

4폰으로 감시하기 (보너스)

  1. 폰에 Orca IDE 앱 설치 (앱스토어 / 안드로이드는 GitHub 릴리즈 APK)
  2. PC Orca에서 페어링 QR → 폰으로 스캔
  3. 침대에서 AI들 실시간 감시 + 지시 (같은 와이파이, 통신 암호화)

⚠️ 자주 막히는 곳

  • npm 없다고 나옴 → nodejs.org에서 LTS 설치 후 터미널 재시작
  • 에이전트가 안 보임 → 터미널에서 claude 단독 실행되는지 먼저 확인
  • Orca는 무료지만 안에서 돌리는 AI는 각자 구독 필요 (클로드 Pro, ChatGPT Plus 등)
